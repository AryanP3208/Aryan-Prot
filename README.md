# Aryan-Prot Portfolio

Welcome to Aryan Patel's professional portfolio and project showcase. This repository contains both a personal portfolio website and featured projects demonstrating AI and software development capabilities.

## Featured Projects

### 🎤 UniVoice - Unified Voice Communication Platform
An innovative AI-powered voice communication platform that breaks language barriers through:
- Advanced speech recognition and processing
- Real-time language translation
- Multi-platform integration
- Interactive voice assistant capabilities

**Technologies Used:** Python, TensorFlow, Speech Recognition APIs, WebRTC, Modern Web Technologies

**[View UniVoice Project →](./univoice/index.html)**

## Portfolio Structure

- `index.html` - Main portfolio website
- `univoice/` - UniVoice project files
  - `index.html` - UniVoice project page
  - `styles.css` - UniVoice styling
  - `script.js` - Interactive demo functionality

## Local Development

1. Clone the repository
2. Open `index.html` in a web browser for the portfolio
3. Open `univoice/index.html` for the UniVoice project
4. Or use a local server: `python -m http.server 8080`
